# Python Chapter 3 — Strings

This repository contains my practice programs and exercises from **Python Chapter 3**. This chapter focuses on working with strings, accessing characters using indexes, slicing strings, using string functions, and working with escape sequences.

## Topics Covered

### 1. Strings

Learn the basics of strings in Python, including:

- Creating strings
- Printing strings
- Accessing characters
- Concatenating strings
- Working with string values

### 2. Negative Indexing and Slicing

Learn how to access characters and parts of a string using negative indexes and slicing.

Basic slicing syntax:

```python
string[start:stop:step]
```

Practice includes:

- Positive indexing
- Negative indexing
- Basic string slicing
- Slicing with start and stop positions
- Using negative indexes in slicing
- Reverse slicing

### 3. String Functions

Practice commonly used Python string functions and methods, such as:

- `len()`
- `lower()`
- `upper()`
- `strip()`
- `replace()`
- `find()`
- `count()`
- `startswith()`
- `endswith()`

### 4. Escape Sequences

Learn how to use escape sequences inside Python strings.

Examples include:

- `\n` — New line
- `\t` — Tab
- `\\` — Backslash
- `\'` — Single quotation mark
- `\"` — Double quotation mark

## Topics Practiced

- Python strings
- String indexing
- Negative indexing
- String slicing
- Negative slicing
- String functions and methods
- Escape sequences
- String manipulation

## Learning Goal

The goal of this chapter is to build a strong understanding of Python strings and become comfortable with indexing, slicing, string functions, and escape sequences.
